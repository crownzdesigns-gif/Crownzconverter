# CrownzConverter
Convert, compress and edit video, audio, image, PDF and GIF files in your browser. Files are processed on your device and never get uploaded.

**Live:** https://crownzconverter-phi.vercel.app

## Built with
Claude Code · ffmpeg.wasm · Vercel

## Features
- 67 tools in three groups: Convert (38), Compress (8), Edit (21)
- Free for files up to 1 GB
- Compress to an exact target size
- Crop, trim, merge, split and make GIFs
